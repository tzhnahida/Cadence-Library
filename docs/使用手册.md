## 4. 新元件入库

### 4.1 一键入库（MCP）
`ingest_lcsc_part(code="C2040")` → 分类符号 + STEP + CIS 行。

### 4.2 分步
| 需求 | MCP 工具 | 命令行 |
|---|---|---|

### 4.3 手工导出库入库（AI 自动分类）
1. 你告诉 AI 手动导出的库路径（`.OLB`/目录）
2. `classify_export_library(path)` → 分类建议
3. `merge_export_library(path, mapping)` → 合并进 `Library\OrCAD\<分类>.OLB`

## 5. AI 定制建符号（按你的版式）

```
① symbol_plan_questions(code / csv_path)
     → 引脚草案 + 自动分组/单元建议 + 要你确认的问题
② 你回答：单元怎么分、哪些引脚一组、单侧组间空几位
③ build_symbol_styled(spec, merge_category)
     → 生成符号（多单元/左右分组/组间空位）
④ one_to_one_check()
     → 一件一封装检查
```

**版式参数**（spec.style）：
- `pin_pitch: 10` 房子风格引脚间距（老库标准）
- `group_gap_slots: 1` 组间空**一个引脚位**（Δ=2×pitch）
- `group_gap: 0` 不额外加间距
- 单脚可写 `"gap": 1`（该脚前再空一位）；`side` / `group` / `unit` 控制左右/分组/单元

## 6. CIS 维护

| 操作 | MCP 工具 | 命令 |
|---|---|---|
| 体检 | `cis_audit` | `pwsh cis_audit.ps1 -Mdb <db>` |
| 清理 | `cis_cleanup` | `pwsh cis_cleanup.ps1 -Mdb <db> -LogDir out` |
| R/C 网格重生 | `regen_passives` | `pwsh cis_regen_passives.ps1 -Mdb <db>` |

- 清理/重生前自动备份为 `*.mdb.bak_<时间戳>`
- 电阻 6921 行、电容 6912 行（E96 × 全封装），Part_ID 尽量沿用旧值
- 新料号用 `ingest_lcsc_part`，**不要手工改 Part_ID**

### 6.1 自动补 datasheet

```bash
# 只扫描（列出空/搜索页/文件不存在的行）
python fetch_datasheets.py --scan

# 自动补（TI 型号走 ti.com 直链，下载后校验型号再存盘回填）
python fetch_datasheets.py --apply
python fetch_datasheets.py --apply --codes C2651884,C2864299
```

- 保存为 `Library\Datasheet\Chip_<分类>_<型号>.PDF`，CIS 的 Datasheet 回填文件名
- 校验：`%PDF` 头 + 文本里出现型号前缀，避免拿错器件
- MCP 工具：`fill_datasheets(codes="", apply=True)`

### 6.2 封装/符号核对（MCP）

| 工具 | 用途 |
|---|---|
| `dump_footprint(dra_path)` | SKILL 读 `.dra`：引脚号/坐标/padstack（只读副本） |
| `check_footprint(dra_path, code)` | 单封装 5 项核对（vs LCSC）：脚数/EP/pitch/pin1/焊盘 |
| `check_new_parts()` | 只核 LCSC 新件：有 .dra 的做 5 项核对，没有的报告缺封装 |
| `check_footprints_batch()` | 按 CIS 参数化封装串批量核对 |
| `compare_old_library()` | 当前 Footprints vs 老库逐文件哈希一致性 |
| `verify_olb(olb_path)` | 开源 OpenOrCadParser 独立校验 .OLB（不依赖 Capture） |

> 老封装只做"与老库一致"核对；新件才做几何核对（用户 2026-10-24 定规）。

## 8. 故障排查

| 现象 | 处理 |
|---|---|
| CIS 查不到料 | 32 位 ODBC（`SysWOW64\odbcad32.exe`）把 DSN `CIS` 指到 `CIS\Components_Pro.mdb` |
| 3D 加载不到 | Allegro `steppath` 加 `Library\3D` |
| `.OLB` 写不进 | 关掉 Capture；`ProLibrary` 残留的 `.OLBlck` 锁文件在关闭后删掉 |
| `regen_passives` 报错 | 必须 PowerShell 7（`pwsh`）；PS5.1 中文/± 编码会炸 |
| 符号/封装找不到 | 检查 `OrCAD\*.OLB` 与 `Allegro\Footprints` 路径 |
